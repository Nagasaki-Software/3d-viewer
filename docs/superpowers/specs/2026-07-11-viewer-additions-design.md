# ビューア追加機能 設計書（タイトル・スペック・展示モード・回転中心・変換ツール修正）

作成日: 2026-07-11
対象: `apps/3d-viewer`（viewer / converter）
前提: 2026-07-09 全面見直し設計書・実装（masterマージ済み）の上に追加する。

## 1. 背景

展示会・プレゼンでのショーケース利用と、日常操作の改善のため、以下を追加する。

1. 機器・装置の名称（タイトル）とスペックの常時表示
2. 展示モード（ターンテーブル自動回転）
3. 回転中心の任意設定
4. 変換ツールの「STEPファイルを読み込み中」が表示されない不具合の修正

## 2. タイトル・スペック表示（viewer）

- **タイトルカード**: 画面左上、角丸長方形。機器・装置名を表示。初期値はGLBファイル名（拡張子なし）
- **スペックカード**: 画面左下、角丸長方形。タイトルより小さいフォント。複数行の自由記入。未入力時は非表示
- **編集**: 編集モード中にカードをタップすると入力ダイアログを表示。タイトルは1行入力、スペックは複数行入力（既存ダイアログを textarea 対応に拡張）
- **保存**: 保存JSON（v2）に追加フィールド `meta: { title: string, specs: string }` を含める。旧JSONに meta が無い場合は初期値（ファイル名 / 空）とする。互換性は維持
- **パネル重なり対策**: 注釈一覧パネルはタイトルカードの下、ビュー一覧パネルはスペックカードの上に配置をずらす

## 3. 展示モード（viewer）

- 操作パネルに「展示モード」トグルボタンを追加
- ON: OrbitControls の autoRotate によりターンテーブル回転（約30秒/周）。回転中心は現在の回転中心（§4）に従う
- 回転中にユーザーが操作（ポインター操作）すると回転を一時停止し、**30秒間無操作で自動的に回転再開**
- ボタン再押下で展示モードを完全終了（無操作復帰も無効化）
- 状態管理は新規モジュール `exhibit.js` に分離し、タイマーロジックはコールバック注入で単体テスト可能にする

## 4. 回転中心の任意設定（viewer）

- **モデル上の任意点をダブルタップ** → その点を回転中心（OrbitControls target）に設定。タップ点に一瞬マーカーを表示し「回転中心を設定しました」と通知
- **空きスペースのダブルタップ**、または標準ビューボタン → 回転中心をモデル中央（原点）にリセット
- ダブルタップの1回目で部品選択が発火するのは許容する（選択は無害で、2回目のタップで回転中心設定が加わるだけ。抑制のための遅延判定は行わず、応答性を優先する）
- ドラッグ回転・展示モードの回転の双方がこの中心を使う

## 5. 変換ツールの読み込み表示不具合の修正（converter）

**原因（検証済み）**: OCPのSTEP読み込み（C++）がGILを保持し続けるため、ワーカースレッド実行中はGUIのメインループが完全に停止する（実測: 64秒以上）。「読み込み中…」の表示・再描画・応答がすべて止まる。

**対策**: 変換処理をスレッドではなく**別プロセス**（multiprocessing）で実行する。

- 子プロセスで `convert()` を実行し、ステージ通知・完了・エラーを `multiprocessing.Queue` でGUIに送る
- GUI側は既存の `root.after` ポーリングでキューを読む（現行構造を維持）
- Windows の spawn 方式に対応するため、子プロセスのエントリ関数はモジュールレベルに置く（新規 `src/worker.py`）
- 子プロセス起動時のライブラリ読み込みに数秒かかるため、開始直後に「変換プログラムを準備中…」ステージを表示する
- 効果: 「読み込み中…」表示が正しく出る。ウィンドウの「応答なし」も解消

## 6. テスト

- viewer: 展示モードのタイマーロジック（操作で停止→30秒で再開→OFFで無効）、meta付きJSONのパース/ビルド、回転中心リセット条件を vitest で追加テスト。既存23件は維持
- converter: 既存23件のpytestを維持。プロセス間通信（ステージ通知・エラー伝搬）の統合テストを追加
- 実機確認: SampleCar.glb でタイトル/スペック編集・展示モード・回転中心、実STEPで変換ツールの表示

## 7. 対象外

- タイトル/スペックのGLB埋め込み（変換ツール側入力）
- 展示モード中のUI自動非表示
- 回転速度・復帰時間の設定画面（固定値: 約30秒/周・30秒）
