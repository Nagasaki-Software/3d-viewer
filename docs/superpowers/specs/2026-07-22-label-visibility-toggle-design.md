# 注釈ラベルの表示/非表示トグル 設計

## 背景・目的

注釈ラベル（部品名などの吹き出し）は追加すると常に画面に表示され続け、隠す手段がない。ラベルが多いモデルでは3D表示が見づらくなる場面があるため、ワンタップで全ラベルの表示/非表示を切り替えられるボタンを追加する。

## ゴール

- 既存の注釈ラベル・引出し線を、ワンタップで一括して表示/非表示にできる
- 閲覧モード・編集モードのどちらでも使える
- 既存の見た目（トグルボタンの見た目・挙動）と統一する（エッジ表示ボタンと同じパターン）

## スコープ外

- ラベルごとの個別表示/非表示（一括切り替えのみ）
- 状態の保存・復元（プロジェクトJSONへの保存、ブラウザへの記憶。毎回「表示」から始まる）
- 新しいアイコン・グラフィックの導入

## UI設計

既存の「表示設定」折りたたみメニュー（エッジ表示・展示モード・ライトモードの並び）に、同じ見た目のトグルボタン「ラベル表示」を追加する。エッジ表示ボタンと同様に、ONの間は`active`クラスでハイライトする。閲覧・編集どちらのモードでも常に使える（このメニュー自体がモードで隠れないため、追加の配線は不要）。

```
表示設定 ▼
[ラベル表示(ON)] [エッジ表示] [展示モード] [ライトモード]
```

- ボタンの並び順: 「ラベル表示」を先頭に追加（エッジ表示の前）
- 初期状態: ON（`active`クラス付き。既存の「常に表示」という現状の挙動を変えない）

## 技術設計

### annotations.js

- モジュール内フラグ `labelsVisible`（初期値 `true`）を追加
- `setLabelsVisible(visible)` をexportし、フラグを更新する
- 毎フレーム呼ばれる`updateAnnotationPositions()`内の表示判定に`labelsVisible`を追加する。現状は「部品が非表示」「カメラの裏側」の条件で`show`を算出しているため、`labelsVisible === false`の場合も同様に非表示（`show = false`）にする（3条件のOR、いずれか一つでも非表示理由があれば隠す）

### main.js

- `#labels-toggle`ボタンにクリックハンドラを追加
  - クリックのたびに内部フラグを反転させ、`setLabelsVisible()`を呼ぶ
  - ボタンの`active`クラスをトグル後の状態に同期する
- 初期表示時、ボタンに`active`クラスを付けておく（HTML側で`class="active"`を付与）

### index.html / style.css

- `#labels-toggle`ボタンを「表示設定」グループの先頭に追加（`<button id="labels-toggle" class="active">ラベル表示</button>`）
- 新規CSSは不要（既存の`#ui-panel button.active`スタイルを流用）

## テスト方針

表示/非表示の判定はDOM操作を含む既存の`updateAnnotationPositions()`に組み込むため、既存方針（このファイルは純粋関数分離をしていない）に合わせてブラウザでの動作確認とする。新規の純粋関数は発生しないため単体テスト対象なし。

ブラウザで以下を確認する:

- トグルでラベル・引出し線が一括で表示/非表示になること
- 非表示中も部品タップ・カメラ操作（回転/パン/ズーム、ボタン操作含む）など他機能に影響しないこと
- 閲覧⇔編集モードの切り替えでボタンの状態（ON/OFF）が保たれること
- 非表示中に新しいラベルを追加した場合の挙動（追加直後も非表示のままになること）
- ページを再読み込みすると「表示（ON）」に戻ること
