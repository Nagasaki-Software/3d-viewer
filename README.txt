==========================================================
 3Dモデルビューア — 配布の手引き
==========================================================

このフォルダ（3d-viewer）には2つのアプリが入っています。

  1. ビューア（viewer フォルダ）
     ブラウザで3Dモデル（.glb）を表示するアプリ。
     「ビューア起動.bat」をダブルクリックで起動します。

  2. 変換ツール（converter フォルダ）
     CADのSTEPファイルを表示用の .glb に変換するアプリ。
     「変換ツール起動.bat」をダブルクリックで起動します。

----------------------------------------------------------
 まず知っておくこと
----------------------------------------------------------

・モデルを「見るだけ」の人に必要なのはビューアと .glb ファイル
  だけです。変換ツールは、STEPファイルを変換する担当者の
  PCにだけあれば十分です。

・.glb ファイルと注釈ファイル（～_annotations.json）を一緒に
  渡せば、受け取った人はどちらもビューアにドラッグ＆ドロップ
  するだけで、同じ注釈・ビュー・タイトル付きで見られます。

----------------------------------------------------------
 パターンA: 他のPCにアプリごと配布する
----------------------------------------------------------

【渡すもの】
  この 3d-viewer フォルダ一式をUSBメモリ等でコピーします。
  ※ 次のフォルダはサイズが大きいためコピーから除いてよい：
     viewer\node_modules （受け取り側で自動再作成されます）
     converter\.venv     （受け取り側で作り直します）

【受け取ったPCで必要な準備（初回のみ）】

   1. Node.js をインストール（https://nodejs.org/ からLTS版）
   2. 変換ツールも使う場合（変換担当者のみ）は、Python 3.12 を
      インストール（https://www.python.org/）
      ※ インストール画面の「Add Python to PATH」にチェックを入れる
   3. 「初回セットアップ.bat」をダブルクリック
      （部品をインターネットから入れます。10～20分ほどお待ちください。
        Python 3.12 が無い場合は、変換ツールの準備だけ飛ばします）
   4. ビューアは「ビューア起動.bat」、変換ツールは「変換ツール起動.bat」
      をダブルクリック

----------------------------------------------------------
 パターンB: 社内LANで共有する（1台で動かして皆で見る）
----------------------------------------------------------

  1. サーバー役のPCで、見せたいモデルを次のフォルダに置く:
       <このフォルダ>\viewer\models\
     ・GLBファイルをそのままコピーするだけです
     ・注釈も見せたい場合は、ビューアで保存したJSONを
       「<モデル名>_annotations.json」の名前で隣に置きます
  2. サーバー役のPCで「ビューア起動.bat」をダブルクリックする
     （自分のPCで見るときと同じ bat です。起動すると、同じ
       ネットワークの他のPCからも見られるようになります）
     ・起動時に配信用の準備（ビルド）が自動で行われます。
       黒い画面にメッセージが流れて1分ほどかかることがあります
     ・一度見たモデルは各自のPCに記憶され、2回目以降は
       ダウンロードなしで素早く表示されます
  3. 画面に表示される「Network: http://192.168.～:4000」の
     アドレスを控えて、皆に知らせる
  4. 他の人は自分のPCのブラウザでそのアドレスを開く
     → 最初の画面に「サーバー上のモデル」一覧が出るので、
       タップするだけでモデル+注釈が表示されます
     → 特定のモデルを直接開くURLを共有することもできます:
       http://192.168.～:4000/?model=モデル名
     （従来どおり各自の .glb をドラッグ＆ドロップも可能）

  ※ 初回起動時にWindowsファイアウォールの許可ダイアログが
     出たら「アクセスを許可する」を選んでください。
  ※ サーバー役PCのIPアドレスは、コマンドプロンプトで
     ipconfig と入力しても確認できます（IPv4アドレスの欄）。
  ※ 社外のネットワークには公開しないでください。

----------------------------------------------------------
 困ったときは
----------------------------------------------------------

・ビューアが起動しない → Node.js が入っているか確認し、
  「初回セットアップ.bat」をもう一度実行
・変換ツールが起動しない → Python 3.12 が入っているか確認し、
  「初回セットアップ.bat」をもう一度実行
・日本語の部品名が文字化けする → 既知の制限です
  （converter\README.md の「既知の制限」参照）
